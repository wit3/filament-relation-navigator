# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep discussions about the code.
Harassment and personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainer through
[GitHub](https://github.com/wit3), or with a
[private security advisory](https://github.com/wit3/filament-relation-navigator/security/advisories/new)
if it is urgent.
