# Security policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through
[GitHub's private vulnerability reporting](https://github.com/wit3/filament-relation-navigator/security/advisories/new).
You will get an answer within a few days; once a fix is released, the
advisory is published with credit to you, unless you prefer otherwise.
