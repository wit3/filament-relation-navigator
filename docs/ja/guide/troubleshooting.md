# トラブルシューティング

## メニューが表示されない

- ページで `HasRelationNavigator` を使う必要があります。リレーションページには常に含まれています。
- メニューには少なくとも 2 つの項目が必要です。そのページ自身と、もう 1 つです。
- 独自のパンくずリストを組み立てるページは、`$this->withRelationNavigator([...])` を返す必要があります。
- 40rem 未満では Filament がパンくずリストを非表示にします。メニューは見出しの上に移動します（`menu.mobile`）。

## メニューの表示が崩れる、またはキャレットの位置がずれる

更新のたびに、プラグインのスタイルシートを公開し直してください。

```bash
php artisan filament:assets
```

## リレーションページが 404 になる

- リレーションマネージャーにページがありません。リソースに `HasRelationPages` があるか、リレーションマネージャーに `InteractsWithRelationPage` があり、かつ除外されていない必要があります。
- スラッグがリソースのページキー（`edit`、`view`...）と同じです。そのようなスラッグはスキップされます。`$relationPageSlug` で別のスラッグを指定してください。
- ルートをキャッシュしている場合は、デプロイ後にキャッシュし直してください：`php artisan route:cache`。
- ポリシーがレコードを「見つからない」として拒否しています（`Response::denyAsNotFound()`）。これは意図どおりの 404 です。

## リレーションページが 403 になる

リレーションページには、詳細ページの `canAccess()`、レコードの `view` ポリシー（編集ページの場合は `update`）、リレーションマネージャーの `canViewForRecord()`、そして定義している場合はリソースの `canAccessRelationPage()` が必要です。この順番で確認してください。

## バッジが表示されない

- `menu.badges` が `false` になっているか、ページやリソース、またはリレーションマネージャー（`hasRelationNavigatorBadge()`）で無効になっています。
- デフォルトでは、メニューを開いたときにスピナー付きで読み込まれます。スピナーが止まらない場合は、ブラウザのコンソールで Livewire リクエストが失敗していないか確認してください。
- 1.3 より前に公開したビューは、後からバッジを読み込めません。代わりにページと一緒に受け取ります。

## ショートカットが反応しない

- フィールドに入力している間は何もしません。
- パネルのグローバル検索のショートカット（`globalSearchKeyBindings()`）は横取りしません。`menu.shortcut` で別のショートカットを選んでください。
- ブラウザの拡張機能やオペレーティングシステムが同じキーを使っている可能性があります。

## 「ページとして開く」が表示されない

- `relation_manager_link` が `false` になっているか、リソースまたはリレーションマネージャーで無効になっています。
- リレーションマネージャーに専用のページがないか、すでにそのページを開いています。
- カスタムの `->header()` ビューを使うテーブルには、ヘッダーアクションを置く場所がありません。

## 前後のボタンが表示されない

- デフォルトでは無効です：`record_navigation`。
- 他のレコードがない場合は表示されません（ネストされたリソースでは、同じ親を持つ他のレコードがない場合）。
- 一覧の並び順に従うには、設定またはリソースでレコードナビゲーションを有効にした状態で、このセッション中にその一覧を開いている必要があります。

## 「A directory that only this user can write」

ストレージが読み取り専用のため、生成されたページクラスがシステムの一時ディレクトリに書き込まれますが、そのディレクトリの所有者が別のユーザーになっています。`storage/framework/cache` を書き込み可能にするか、メッセージに示されたディレクトリを削除するか、サービスプロバイダーで別のディレクトリを指定してください。

```php
GeneratedRelationPages::useCachePath(storage_path('app/relation-pages'));
```

## それでも解決しない場合

[GitHub Discussions](https://github.com/wit3/filament-relation-navigator/discussions) で質問するか、Filament のバージョンと再現できる数行のコードを添えて [Issue](https://github.com/wit3/filament-relation-navigator/issues) を作成してください。
